# Simple Python Calculator

A basic calculator implementation in Python for arithmetic operations.

## Features
- Addition, Subtraction, Multiplication, and Division.
- Safety check for division by zero.

## How to Run Tests
This project uses the built-in `unittest` module. To run the tests, execute the following command in your terminal:

```bash
python -m unittest test_calculator.py
```

## Usage
You can import the functions into your own script:

```python
from calculator import add, divide

print(add(5, 3))    # Output: 8
print(divide(10, 2)) # Output: 5.0
